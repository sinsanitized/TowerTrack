# Record an Event workflow and New York State sampling trace

## Rule matrix

| Sampling type                    | Applies to                                                                                                                       |                                                                                                                                                          Frequency | Regulatory source                                                                       | Legal owner                                                                                        | TowerTrack company workflow                                                                                                             |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | -----------------------------------------------------------------------------------------------------------------------------------------------------------------: | --------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| Routine bacteriological culture  | Cooling tower recirculating water; heterotrophic bacterial populations measured by HPC, dip slides, or a similar industry method |                                                                                                                                  No more than 30 days while in use | 10 NYCRR §§4-1.2(a), 4-1.4(b)(1); NYSDOH Cooling Tower Registry Guide §4.4.3            | Cooling-tower owner must ensure the MPP schedule, performance, records, and reporting              | Owner/external-provider managed. Technicians are not assigned this action. An authorized office user may confirm documented completion. |
| Legionella culture               | Cooling tower recirculating water                                                                                                | Within 14 days after seasonal startup; then no more than 90 days while in use. Year-round towers also sample within two weeks after startup following maintenance. | 10 NYCRR §4-1.4(b)(2); NYSDOH Cooling Tower Requirements and Registry Guide §4.4.4      | Cooling-tower owner must ensure completion; culture analysis must use an ELAP-certified laboratory | Our field staff collect the sample and the office/laboratory workflow records the result.                                               |
| Potable-water Legionella testing | Building potable-water system in covered Article 28 hospitals and residential health-care facilities                             |                                                                                                                                          Profile and plan specific | 10 NYCRR Subpart 4-2; NYSDOH Hospital and Residential Health Care Facility Requirements | Covered health-care facility                                                                       | Outside the TowerTrack cooling-tower workflow.                                                                                          |

The bacteriological and Legionella cultures are separate analyses. TowerTrack
does not merge their obligations or allow one event to complete the other.

For a tower using NYC Chapter 8 plus New York State rules, the stricter NYC
Legionella interval controls the single physical Legionella collection action.
The composed rule retains both citations. The NYS bacteriological culture clock
remains separate.

## Event workflow classification

| Event                                | Frequency / role                   | Performed by                 | Location                                                                      |
| ------------------------------------ | ---------------------------------- | ---------------------------- | ----------------------------------------------------------------------------- |
| Legionella sample                    | Frequent field action              | Field staff                  | Primary                                                                       |
| Legionella result                    | Frequent office/lab action         | Office/lab workflow          | Primary                                                                       |
| Inspection                           | Frequent field action              | Qualified field staff        | Primary                                                                       |
| Disinfection                         | As-needed field action             | Qualified field staff        | Primary                                                                       |
| Cleaning                             | Approximately twice yearly         | Field staff                  | More Event Types                                                              |
| Hyperhalogenation                    | Seasonal                           | Field staff                  | More Event Types                                                              |
| Startup / shutdown                   | Infrequent operational event       | Field/office                 | More Event Types                                                              |
| Emergency condition                  | Infrequent operational event       | Field/office                 | More Event Types                                                              |
| Weekly biological indicator result   | Corrective-chain event             | Field/office                 | More Event Types                                                              |
| Routine bacteriological sample       | Owner-managed recurring obligation | Owner/external provider      | Office confirmation inside More Event Types; hidden from normal field actions |
| Certification and registry reporting | Administrative                     | Owner/authorized office user | Obligation-specific controls, not a generic field event button                |
